## Evidence, identity and provider boundaries

- The API sends PDF bytes over a private Unix socket to ClamAV. It requires a complete clean response and a current daily signature timestamp. Scanner errors, malformed replies and stale definitions leave new bytes quarantined. A detected upload receives HTTP 422. The application and certificate workflows record the scan result on immutable revisions. A clean certificate re-submission can reference the same content digest while preserving the original quarantine. Owner and appointed-reviewer authorization remains server-side.
