## Release-image and office-scope findings

**Verified failure in the previous scope check, repaired.** Selecting the quota-transfer inbox as Admin used the broader application query. A current out-of-department acting HoD with an additional Admin grant could read another department’s transfer dossier. The inbox now requires academic oversight, limits a HoD query by effective department and preserves Principal’s institutional read. The detail independently checks the current HoD office in the case department. A combined-grant regression covers both entry points on PostgreSQL. [Service](../../apps/api/akus/applications/router.py) · [Regression](../../apps/api/tests/test_admission.py#L393)

**Verified release risk remains open.** Trivy 0.76.2 scanned all six local image exports before and after remediation, using the same advisory database and no mounted volumes. The application-family Dockerfile removes pip after installation and takes the Debian zlib security update. The PostgreSQL image uses the same upstream server version and the vendor zlib update. Caddy web and proxy received all eleven reported Alpine package fixes. Application lockfile results alone missed the installer’s bundled packages. Before/after rows are per image and repeat shared base layers. [Image counts and outstanding high/critical inventory](system-audit-image-advisories.md)

The patched DB still has two critical matches. Debian lists no fixed version for its libxml2 package in the audit database. The other match is the Go standard library embedded in PostgreSQL’s gosu privilege-dropping helper. The audited official image still packages that binary. Caddy also contains high-severity Go-module findings. The scan establishes package matches. Runtime reachability was not established by this audit. Require a patched or qualified upstream build, or a documented, accountable risk disposition with deployment-specific evidence, before release. Owners are infrastructure security and the service operator. The local proxy binds loopback and PostgreSQL has no host-published port.

Orca 46.1 generated four control names and roles as focus moved through the anonymous login and recovery pages in Chromium. This exercise used a private virtual display and D-Bus session. Audio playback, human usability and physical-device testing remain open. [Screen-reader evidence](system-audit-screen-reader.txt)

## Post-audit controls and residual risk

Infrastructure remediation cleared the gosu critical, reduced Caddy package findings and patched the scanner base. The current Debian libxml2 package remains affected and linked to PostgreSQL. The original volume and manifests survived the rollout. The local scanner now rejects a harmless detection specimen and quarantines incomplete verdicts and stale definitions. Its scan result cannot award academic credit. The provider guard rejects known course metadata as personal proof.
