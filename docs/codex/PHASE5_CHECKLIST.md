## Recovered final-check defects

The first office-rotation fixture attempted an unversioned appointment change. It now uses the actual source commands and checks the distinct denials for a former officeholder and institutional oversight. If invalidation decides a case during separation review, the seat releases once and the separation dossier links the invalidation with chronology left unadjudicated. An uphold instead retains the seat until the applicable separation decision.

The retained data also exposed unrelated worker wakeups on quota publication and two browser assumptions about an unfiltered directory and an outgoing employment-history page. The corrected tests exercise normal search and the destination register. The quota test retains its 20-second deadline.
